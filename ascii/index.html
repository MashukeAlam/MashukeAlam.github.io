Embedding These Scenes

These animated ASCII pieces are built with clean TypeScript and require zero dependencies. You can embed any scene into any web page or framework with one HTML tag or pure JavaScript: 

<script type="module" src="https://ascii.rest/ascii.js"></script>
<ascii-art piece="aurora-fjord"></ascii-art>
